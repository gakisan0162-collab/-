# 快適席くじ

GitHub Pagesで動く「温度差を考慮したランダム席替え」プロトタイプです。

## 仕組み

- 生徒は出席番号を入力すると自分の席だけ確認
- 先生は先生用画面で全員の席を事前確認
- `round`（抽選番号）が同じなら、どの端末でも同じ席配置
- 「新しい抽選を作る」で新しい抽選番号を発行
- 新しいURLを生徒に共有するだけで次の席替え
- サーバー不要

## 席の条件

次回以降の空席：
- A1
- A7
- F1

A側＝窓・エアコン側で寒い
F側＝廊下側で比較的暖かい
F7＝ドアの出入りが多い
前方希望者＝1～3行

## GitHub Pages

1. GitHubで新しいPublic repositoryを作る
2. `index.html`、`style.css`、`app.js`をアップロード
3. Settings → Pages
4. Deploy from a branch
5. Branchを `main`、folderを `/ (root)` にする
6. 数分待つとURLが発行される

## 先生用PIN

現在は `2468`。

ただし、GitHub Pages上のJavaScriptに書かれたPINは本当のセキュリティではありません。
学校内の探究プロトタイプとして使う想定です。

実際に個人情報を守る必要がある運用にする場合は、Firebaseなどの認証付きバックエンドに変更してください。

## 注意

このバージョンでは、アンケートの「エアコン時の感じ方」を温度傾向の中心として使っています。
「エアコンの風に強い/弱い」を直接質問していないため、それ自体を測定したデータではありません。
次回アンケートでその質問を追加すると、アルゴリズムをさらに改善できます。
